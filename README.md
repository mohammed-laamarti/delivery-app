# Delivery app

## Lecture intelligente des tickets

L’option **Scanner une étiquette** reconnaît les tickets de plusieurs transporteurs et renvoie le code de suivi, le destinataire, le téléphone, la ville, l’adresse, le montant et le commentaire. Les champs restent modifiables avant de créer le colis.

La lecture est locale et gratuite : elle combine le QR/code-barres et l’OCR français, anglais et arabe dans le navigateur. Aucune clé API ni image envoyée à un service externe.

Au premier scan, les fichiers de reconnaissance des langues peuvent être téléchargés par le navigateur, puis mis en cache. Pour le meilleur résultat : utilisez une photo nette, bien éclairée, sans pli, qui montre tout le ticket. Vérifiez toujours les champs avant de créer le colis.
